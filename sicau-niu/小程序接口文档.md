# 寻牛活动小程序接口文档

本文档整理`Sicau Niu`插件当前小程序端会用到的接口，接口来源为`apps/lina-plugins/sicau-niu/backend/api/player/v1`和`apps/lina-plugins/sicau-niu/backend/api/wall/v1`。

## 基础约定

### 接口前缀

插件接口统一挂在宿主插件公开前缀下：

```text
{BASE_URL}/x/sicau-niu/api/v1
```

例如玩家登录接口完整路径为：

```text
POST {BASE_URL}/x/sicau-niu/api/v1/plugins/sicau-niu/player/login
```

### 请求格式

| 类型 | 说明 |
|------|------|
| `Content-Type` | `application/json`，除文件类配套接口外均使用 JSON 请求体。 |
| 时间字段 | 所有具体时间点均为 Unix 毫秒时间戳，例如`1776333600000`。 |
| 经纬度 | 纬度字段为`lat`，经度字段为`lng`，类型均为数字；坐标系全链路使用`GCJ-02`（`wx.getLocation`需传`type: 'gcj02'`），禁止混入`WGS-84`。 |
| 分页字段 | 使用`pageNum`和`pageSize`，未传时由服务端使用默认值。 |
| 日界 | 所有每日限次（激活、签到、偷草、赠草）按北京时间`00:00`切日，以服务器时间为准。 |
| 幂等键 | 喂草、偷草、赠草请求支持可选`requestId`（最长`64`字符）；网络重试时携带同一`requestId`，服务端拒绝重复执行并返回对应`DUPLICATE_REQUEST`错误码，小程序可视为已成功并刷新余额。 |

### 鉴权方式

公开接口不需要鉴权。玩家接口需要先调用微信登录接口获得`token`，之后在请求头携带：

```http
Authorization: Bearer <token>
```

玩家`token`是插件自签的玩家会话令牌，不是管理端后台登录`token`。

### 统一响应

除二进制资源访问外，接口返回统一 JSON 包裹：

```json
{
  "code": 0,
  "message": "OK",
  "data": {}
}
```

业务失败时仍返回统一包裹，`code`为非`0`，并可能包含结构化错误字段：

```json
{
  "code": 51,
  "message": "Token is invalid",
  "data": null,
  "errorCode": "SICAU_NIU_TOKEN_INVALID",
  "messageKey": "error.sicau.niu.token.invalid",
  "messageParams": {}
}
```

小程序端建议以`code === 0`判断业务成功，以`errorCode`做精确业务分支。

## 公开接口详情

### 微信登录

`POST /plugins/sicau-niu/player/login`

使用小程序`wx.login`返回的`code`换取玩家会话`token`，首次登录会自动创建玩家账号。

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | `string` | 是 | `wx.login`返回的临时登录凭证。 |

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | `string` | 玩家会话令牌，后续玩家接口放入`Authorization`请求头。 |
| `playerId` | `number` | 玩家 ID。 |
| `isNewUser` | `boolean` | 是否为首次创建的新玩家。 |

请求示例：

```json
{
  "code": "081xACFa1bZ2..."
}
```

响应示例：

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IlNJQ0FVLU5JVS1QTEFZRVIifQ.eyJwaWQiOjF9.signature",
    "playerId": 1,
    "isNewUser": true
  }
}
```

### 首位激活纪念墙

`GET /plugins/sicau-niu/wall/first-activators`

返回首位激活玩家纪念墙，按激活时间升序排列，最多`120`条。接口不返回手机号、`openid`或设备指纹。

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `list` | `FirstActivatorItem[]` | 首位激活列表。 |

`FirstActivatorItem`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `seq` | `number` | 纪念墙序号，从`1`开始。 |
| `userId` | `number` | 玩家 ID。 |
| `nickname` | `string` | 玩家昵称，可能为空。 |
| `identityType` | `string` | 玩家身份，见枚举说明。 |
| `niuId` | `number` | 被激活牛只 ID。 |
| `niuName` | `string` | 牛只名称，可能为空。 |
| `niuCode` | `string` | 牛只编号，可能为空。 |
| `activatedAt` | `number \| null` | 激活时间，Unix 毫秒。 |

### 校史亮点

`GET /plugins/sicau-niu/wall/highlights`

返回 H5 纪念墙展示用的校史卡片和语录。

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `cards` | `HighlightCard[]` | 校史卡片列表。 |
| `quotes` | `HighlightQuote[]` | 校史语录列表。 |

`HighlightCard`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `number` | 卡片 ID。 |
| `niuId` | `number` | 所属牛只 ID。 |
| `niuName` | `string` | 牛只名称。 |
| `category` | `string` | 卡片分类。 |
| `title` | `string` | 卡片标题。 |
| `content` | `string` | 卡片内容。 |
| `imagePath` | `string` | 图片路径，可能为空。 |

`HighlightQuote`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `number` | 语录 ID。 |
| `content` | `string` | 语录内容。 |

### 纪念墙统计

`GET /plugins/sicau-niu/wall/stats`

返回活动公开统计，所有数据由服务端聚合。

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `activatedNiuCount` | `number` | 已激活牛只数量。 |
| `totalNiuCount` | `number` | 牛只总数量。 |
| `firstActivatorCount` | `number` | 首位激活记录数量。 |

### 纪念墙配置

`GET /plugins/sicau-niu/wall/config`

返回 H5 纪念墙回跳小程序地址。未配置时为空，小程序或 H5 端应隐藏回跳入口。

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `miniappUrl` | `string` | 回跳小程序 URL 或 scheme，可能为空。 |

## 玩家接口详情

以下接口均需要请求头：

```http
Authorization: Bearer <token>
```

### 绑定手机号

`POST /plugins/sicau-niu/player/phone`

绑定微信授权手机号，服务端执行一手机号一账号约束。生产环境优先传`code`，旧版授权可传`encryptedData`和`iv`。

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | `string` | 否 | 新版`getPhoneNumber`授权`code`。 |
| `encryptedData` | `string` | 否 | 旧版手机号加密数据。 |
| `iv` | `string` | 否 | 旧版手机号解密向量。 |
| `phone` | `string` | 否 | 仅开发 Mock 网关使用，真实网关忽略。 |
| `deviceFingerprint` | `string` | 否 | 设备指纹，用于风控分析。 |

响应`data`为空对象。

`VisibleNiuItem`：

### 激活牛只

`POST /plugins/sicau-niu/player/activations`

玩家拍照打卡后上报当前位置，服务端在当前可见且未激活的牛只中自动匹配距离最近的一头。小程序不需要传`niuId`；服务端会校验距离在配置阈值内、玩家当日激活次数限制，并在事务中把匹配到的牛置为公共池已激活状态。服务端会记录成功、附近无未激活牛、最近牛超出`LBS`判距、移动速度异常的打卡尝试；当日次数限制与尝试次数上限拒绝的请求不写入尝试记录。

防作弊约束：

| 约束 | 说明 | 错误码 |
|------|------|--------|
| 当日激活上限 | 每个自然日（北京时间）最多激活成功`1`次。 | `PLUGIN_SICAU_NIU_ACTIVATION_DAILY_LIMIT` |
| 当日尝试上限 | 每个自然日打卡尝试（含失败）默认最多`20`次，运营端可调。 | `PLUGIN_SICAU_NIU_ACTIVATION_ATTEMPT_LIMIT` |
| 移动速度异常 | 与上次上报位置间的移动速度超过默认`25`米/秒（运营端可调）时拒绝，并记入风控记录。 | `PLUGIN_SICAU_NIU_ACTIVATION_SPEED_ANOMALY` |
| 附近无牛 | 失败响应不携带任何距离或方位提示，防止三角定位扫描。 | `PLUGIN_SICAU_NIU_ACTIVATION_NO_NEARBY_NIU` |

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `lat` | `number` | 是 | 玩家上报纬度（`GCJ-02`）。 |
| `lng` | `number` | 是 | 玩家上报经度（`GCJ-02`）。 |
| `photoPath` | `string` | 否 | 激活照片存储路径，仅作为证据路径，不做图像识别。 |

响应`data`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `niuId` | `number` | 服务端匹配并激活的牛只 ID。 |
| `isFirst` | `boolean` | 是否为该牛只首位激活者。 |
| `orderNo` | `number` | 到达顺序，从`1`开始。 |
| `activatedAt` | `number \| null` | 激活时间，Unix 毫秒。 |
| `card` | `ActivationCard \| null` | 激活时发放的牛只主卡片。 |

`ActivationCard`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `category` | `string` | 卡片分类，见枚举说明。 |
| `title` | `string` | 卡片标题。 |
| `content` | `string` | 卡片内容。 |
| `imagePath` | `string` | 卡片图片路径，可能为空。 |

请求示例：

```json
{
  "lat": 30.123456,
  "lng": 103.123456,
  "photoPath": "sicau-niu/activation/1.jpg"
}
```

响应示例：

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "niuId": 1,
    "isFirst": true,
    "orderNo": 1,
    "activatedAt": 1776333600000,
    "card": {
      "category": "spirit",
      "title": "川农大精神",
      "content": "爱国敬业、艰苦奋斗、团结拼搏、求实创新",
      "imagePath": "sicau-niu/card/1.jpg"
    }
  }
}
```

## 可选配套接口

### 文件上传和图片访问

当前`Sicau Niu`插件玩家接口没有小程序专用上传端点。`激活牛只`接口中的`photoPath`是一个已上传文件路径字符串，不接收文件流。

宿主存在管理端文件接口：

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 上传文件 | `POST` | `/api/v1/file/upload` | `multipart/form-data`，字段名`file`，另传`scene`。该接口是宿主管理端权限接口，不能直接使用玩家`token`调用。 |
| 访问文件 | `GET` | `/api/v1/uploads/*path` | 公开读取已记录的上传文件 URL。 |

如果小程序需要上传激活照片或头像，应先确认是否开放小程序专用上传服务；否则`photoPath`和`avatar`可先由小程序传外部 CDN URL 或空值。

## 常见业务错误

业务错误以统一响应中的`errorCode`为准。以下是小程序端常见需要处理的错误类型：

| 场景 | 建议处理 |
|------|----------|
| `token`无效或过期 | 清理本地`token`，重新调用微信登录。 |
| 手机号已被绑定 | 提示用户该手机号已绑定其他账号。 |
| 学生资料未选择院系或年级无效 | 引导用户补全身份资料。 |
| 附近没有可激活牛或超出`LBS`判距 | 刷新地图牛只列表，提示用户靠近未激活点位后重试。 |
| 当日已激活过牛只 | 提示每日激活次数限制。 |
| 余额不足 | 引导签到、偷草或等待赠草。 |
| 已签到 | 提示今日已领取。 |
| 偷草目标无效或次数已满 | 刷新偷草目标或提示今日次数已用完。 |
| 赠草数量过小或次数已满 | 按服务端规则提示调整数量或明日再试。 |
| 证书未拥有 | 引导完成对应荣誉条件。 |

## 推荐调用流程

### 首次进入小程序

1. 调用`POST /plugins/sicau-niu/player/login`获取`token`。
2. 调用`GET /plugins/sicau-niu/player/profile`判断是否已绑定手机号和完善身份。
3. 如需补全资料，调用`POST /plugins/sicau-niu/player/phone`和`PUT /plugins/sicau-niu/player/profile`。
4. 调用`GET /plugins/sicau-niu/player/niu`渲染地图点位。

### 激活和喂草

1. 调用`GET /plugins/sicau-niu/player/niu`获取可见牛只。
2. 用户到点位拍照打卡后调用`POST /plugins/sicau-niu/player/activations`，只上报`lat`、`lng`和可选`photoPath`。
3. 激活成功后记录响应中的`niuId`，调用`GET /plugins/sicau-niu/player/cards`刷新图鉴。
4. 调用`GET /plugins/sicau-niu/player/grass`确认余额后，使用激活响应中的`niuId`调用`POST /plugins/sicau-niu/player/feedings`喂草。
5. 调用`GET /plugins/sicau-niu/player/feedings`刷新喂草轨迹。

### 社交和排行

1. 调用`POST /plugins/sicau-niu/player/checkin`领取每日草料。
2. 调用`GET /plugins/sicau-niu/player/steal-targets`获取偷草目标。
3. 调用`POST /plugins/sicau-niu/player/steals`或`POST /plugins/sicau-niu/player/gifts`完成社交行为。
4. 调用三个排行接口刷新榜单。
5. 调用`GET /plugins/sicau-niu/player/messages`展示消息入口。
